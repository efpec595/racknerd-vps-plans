**嵌套虚拟化被明确禁止。** 服务条款里写了，在 KVM VPS 里再跑虚拟机、开 VPS 转售、跑需要硬件虚拟化的模拟器，都不允许，除非拿到书面批准。Docker、Docker Compose、LXC/LXD、Kubernetes、K3s 这类容器用法不受这条限制。想买一台机器开小鸡分给别人，这条路走不通。

**VPS 默认不含托管备份。** 除非单独购买备份服务，官方不对数据完整性负责，建议自己定期往外部同步。这一点跟共享主机不一样，共享主机那套自动备份的待遇不适用于 VPS。

**Windows 是另一条产品线。** 常规 KVM 套餐只能装 Linux，默认可选的系统有 Debian、Ubuntu、CentOS、Rocky Linux、AlmaLinux、Fedora 这些，也能开工单申请自定义 ISO。需要 Windows Server 得去专门的 Windows VPS 产品线，NVMe 硬盘、带授权，价格比 Linux 套餐高一截。

## ctrl 面板能干什么，配置该按什么标准挑

老文章里写的是 SolusVM 面板，现在新开的特价套餐给的是 ctrl，这是 RackNerd 自己做的控制面板。功能比只看「重启、重装」要多：面板里能做重启、重装系统、开 HTML5 VNC 控制台、重置 root 密码、设入站防火墙规则、升级套餐，还能一键装应用。

一键应用这一项直接影响你该买多大内存。官方说明里给的门槛是这样的：OpenClaw 至少要 8GB 内存，Hermes Agent、AnythingLLM、Ollama、LibreChat 至少要 4GB，n8n 和 Coolify 从 2GB 起比较舒服。Docker 加 Portainer 也能一键装，装 WordPress 可以走 AdminBolt、CyberPanel 或 CloudPanel 这几个一键应用，也可以自己用 SSH 慢慢配。

换句话说，如果你只是想跑个静态站、轻量爬虫、定时任务或者自用节点，1GB 那档年付款足够。想在机器上跑本地大模型、跑 AI Agent 类应用，4GB 是起点，8GB 才谈得上舒服，这时候该看的是 4GB 年付 $43.88 或者官网特价页的 6GB 档。

开通速度这块，官方说的是即时激活，实际操作里通常 5 分钟内能收到 IP 和登录信息。付款支持 PayPal 和各大信用卡，国内银行的 Visa、Mastercard 一般能刷。

## 常见问题

**国内访问速度怎么样？**
看机房。洛杉矶 DC-02 和圣何塞大概在 150–200ms，圣何塞常见区间是 150–180ms；东海岸节点 200ms 以上。晚高峰表现跟运营商路由有关，电信相对稳，联通移动波动大。

**能装 Windows 吗？**
常规 KVM 套餐不行，只能装 Linux。Windows Server 走单独的 Windows VPS 产品线，含授权，价格更高。

**一个账户能管多台机器吗？**
可以。ctrl 面板里能同时管理多台，重启、重装、看流量都在面板里完成，不用每次开工单。

**以后能升级配置吗？**
能升级，升级要重启一次，停机很短。降级不支持。

**有退款或者试用吗？**
没有。官方明确不提供退款和退款保证，下单前用机房测速节点自己验。

**IPv6 怎么申请？**
下单后开一张工单申请，洛杉矶 DC-02、犹他、多伦多、法国、都柏林这几个机房支持，每台最多 100 个地址，不收费。

**工单是中文还是英文？**
中文提交客服看得懂，回复会用英文。一般一小时内有人回。
